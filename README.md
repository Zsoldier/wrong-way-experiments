# wrong-way-experiments
A collection of experimental IoT and smart home integrations using Raspberry Pi and other devices

## Projects

- [`august-unifi-door-monitor`](projects/august-unifi-door-monitor/) — Raspberry Pi Zero W service that
  polls August/Yale Access smart lock state via the `yalexs` API and reflects lock + door position
  state to a UniFi Access UA Hub Door Mini via GPIO-driven dry-contact relay signaling.
